## 6. Design decisions

- **Decision:** The reference is developed in a private clone (.agents-wd) with its own handoff history; the public repo is an export produced by publish.sh and ships one genesis entry.
  **Why:** A bare clone of the public repo must not hand a new project the reference's own work as its HEAD.
  **Alternatives rejected:** A project-shaped private repo with the reference under a subfolder (two copies to keep aligned); zero entries with the exploration text in pickup (the human chose a visible first entry).
- **Decision:** The genesis entry lives as an asset of wax_setup and is seeded by lib.sh for both setup.sh and publish.sh, with placeholders for stem, project, and version.
  **Why:** One source for the text; the seeded stem is the real install time, so any later entry sorts after it (R-08).
  **Alternatives rejected:** A fixed stem checked into the public repo (drifts from the asset).
- **Decision:** The version token is the literal "WAX 1.0" in AGENTS.md and README.md; check.sh fails on mismatch.
  **Why:** The human asked for the version in both files; one regex keeps them honest without a seventh top-level file (R-13).
  **Alternatives rejected:** A VERSION file (R-13); semver 1.0.0 (the human said "1.0").
- **Decision (R-03 deviation, human instruction):** Read and edited README.md despite P-01 and P-05. Instruction: "vertion controll should live in both agents.md adn readme.md".
  **Why:** The version cannot be put into a file the agent may not open.
  **Alternatives rejected:** Asking the human to paste the line by hand.
- **Decision (R-03 deviation, human instruction):** Edited RULES.md (R-04 wording and skill names) despite R-15. Instruction: "i actually figured we can also rebrand to wax agentix workspace".
  **Why:** The rename cannot leave R-02, R-04, R-15 pointing at xaw_* skills. Precedent: commit 5e21615.
  **Alternatives rejected:** Keeping xaw_ skill names under a WAX brand.
- **Decision (R-03 deviation, human instruction):** Edited AGENTS.md (P-05) for the version line and the rename, same instructions.
  **Why:** AGENTS.md is where the human asked the version to live.

## 7. Philosophical choices

- A distributable must ship in the state its own installer produces; cloning and installing must be indistinguishable to the agent.
- A workspace's first instruction to an agent is to look, not to act.
