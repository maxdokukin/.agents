## 6. Design decisions

- **Decision:** none taken; the following are proposals discussed with the human and not yet accepted (P-10).
  **Why:** The human asked to think and talk, then had to stop.
  **Alternatives rejected:** none

- **Proposal: distribution.** Publish a Claude Code plugin (manifest plus a `skills/` folder, listed in a marketplace manifest) carrying `wax_dot_agents` (setup, upgrade, check) and `wax_handoff`. The plugin bundles a copy of the public `.agents` tree as an asset; plugin version equals the WAX version. The plugin cannot be the public `.agents` repo itself, because a manifest folder would be a seventh top-level item (R-13) shipped into every project. The global `wax_handoff` must follow the SKILL.md inside the project's own `.agents/`, so a newer plugin never rewrites an older project's handoffs by its own rules.
- **Proposal: existing `.agents/`.** Setup detects five cases: (1) absent, fresh install; (2) WAX with a version token, upgrade: replace RULES.md, wax skills, sample_skill, template, README; keep handoffs, PREFERENCES.md, project name, project-added skills and their router rows; write a handoff entry recording the upgrade; per-version migration notes needed (e.g. the Resume key added in this version); (3) RULES.md and handoffs but no version, the XAW era: upgrade plus rename; (4) foreign folder: stop and ask (move aside, merge, abort); merge would need a preference listing tolerated extra top-level items; (5) WAX that fails check.sh: refuse, human repairs.
- **Proposal: root pointer.** Nothing reads `.agents/AGENTS.md` by itself. Setup should offer to write a pointer block into the project's root CLAUDE.md and AGENTS.md, creating them if absent, showing the lines to the human first since those files are project-owned.
- **Proposal, unverified: skills path.** The agent believes Codex discovers project skills under `.agents/skills/` in the same SKILL.md shape. If true, moving `skill/skillset/` to `skills/` would let other agents find WAX skills natively. It changes fixed names (R-13, R-14), so it would be a 2.0 change. Verify against Codex documentation before deciding.
