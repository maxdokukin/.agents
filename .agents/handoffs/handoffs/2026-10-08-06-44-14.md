## 6. Design decisions

- **Decision:** Load skills by symlink, not by copy.
  **Why:** The reference stays the single source; edits there are live in every session.
  **Alternatives rejected:** Copying into ~/.claude/skills/ (would drift); per-project
  .claude/skills/ links (one per repo to maintain).
- **Decision:** setup.sh uses the physical path of its script directory.
  **Why:** Through a symlink the logical path points into ~/.claude/, four levels up of which
  is not the reference.
  **Alternatives rejected:** A --source flag as the only way (it exists, but should not be
  required for the common case).

## 7. Philosophical choices

- Tooling should work from wherever the host discovers it, without the user knowing where the
  files physically live.
