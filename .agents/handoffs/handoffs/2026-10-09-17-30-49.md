## 6. Design decisions

- **Decision:** Migration is a script (migrate.sh) with three modes, and the human's choice is passed as a flag; the agent never decides merge or discard.
  **Why:** The human chose a script over a markdown-only procedure; a deterministic merge is reviewable and testable against real folders, and the explore report gives the agent exact facts to put in front of the human.
  **Alternatives rejected:** Markdown procedure with agent-run moves (asked, declined).
- **Decision:** Nothing is deleted. Merge builds the new tree beside the old, verifies it, then swaps; the old folder becomes .agents.old-`<stamp>`. Discard moves aside first.
  **Why:** Reversible without git; a failed merge leaves the project untouched.
  **Alternatives rejected:** Delete and rely on git (asked, declined).
- **Decision:** Foreign content lives at .agents/project/, tolerated through P-11, which R-13 and check.sh honor.
  **Why:** The human wants all agentic material consolidated inside .agents/. P-11 keeps the fixed top level a rule with one explicit, per-project exception list.
  **Alternatives rejected:** Moving foreign files out of .agents/ (asked, declined); skills-only merge.
- **Decision:** The merge gate uses the old copy's own check.sh, not the installer's.
  **Why:** An older layout can never pass a newer check; the gate's question is "is the old copy consistent by its own rules" (R-09).
  **Alternatives rejected:** Installer's check.sh (first implementation; refused every real upgrade).
- **Decision:** setup.sh and migrate.sh refuse a source that does not hold exactly the genesis entry.
  **Why:** The dev tree (this one) is symlinked into ~/.claude/skills on this machine; without the guard, /wax_init from here would copy 13 dev entries into a project, the original bug this design exists to prevent.
  **Alternatives rejected:** Documentation only.
- **Decision:** Root CLAUDE.md and AGENTS.md are consolidated into .agents/project/root/ only with --consolidate, after the agent suggests it and warns that without a root file sessions must begin with pickup by hand.
  **Why:** The human asked for the suggestion; the warning is factual (nothing loads .agents/AGENTS.md on its own).
  **Alternatives rejected:** Writing a pointer into the root files (asked, declined).
- **Decision:** Version 1.2.
  **Why:** R-04 and R-13 changed and P-11 was added; migrate.sh keys on version tokens, so the token must move.
  **Alternatives rejected:** none
